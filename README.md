# Командный проект: Мобильное приложение «ЧекСкан» (Client-Server Architecture)

Репозиторий содержит архитектуру приложения для сканирования, OCR-распознавания и финансовой аналитики чеков. Проект реализуется командой из 3-х человек (UI/UX + Backend + DB).

---

## 🗺️ UI/UX Сценарии и Техническое задание для Backend-разработки:

Все макеты интерфейса загружены в корневую папку репозитория в формате PNG. Разработчикам бэкенда необходимо реализовать серверную логику под следующие экраны:

### 1. Главная страница — `Главная.png`
* **Бэкенд-логика:** GET-запрос на получение текущего баланса пользователя (`2 840 Br`) и остатка лимита. Массив последних чеков.
* **UI-фича:** Реализована система дизайн-токенов для динамической смены тем оформления (Светлая/Темная).

### 2. Ввод данных и Корректировка — `Камера.png`
* **Бэкенд-логика:** Интеграция OCR-модели. После фото чека сервер распознает текст и возвращает JSON со строками: Магазин, Дата, Сумма, Категория.
* **UX-сценарий:** Нажатие на кнопку «Карандаш» переводит поля в режим редактирования (добавлен визуальный текстовый курсор). По кнопке «Готово» отправляется POST-запрос на обновление данных в БД.

### 3. Аналитика расходов — `Статистика.png`
* **Бэкенд-логика:** Агрегационный SQL-запрос к таблице расходов с группировкой по дням недели (`Ср`, `Суб` и т.д.) и категориям.
* **UX-сценарий:** Настроен интерактивный оверлей (`Open overlay` ➡️ `Manual`). При наведении на столбец динамически всплывает плашка точной стоимости расходов за день.

### 4. Лента транзакций — `История.png` и `Оверлей к истории.png`
* **Бэкенд-логика:** Вывод списка чеков из БД с пагинацией. 
* **UX-сценарий:** Клик по карточке «Евроопт» вызывает нижний `Bottom center` оверлей (`Slide in`), который запрашивает массив позиций чека (Хлеб, Молоко, Сыр) для вывода детализации.

### 5. Настройки профиля — `Профиль.png`
* **Бэкенд-логика:** Интеграция OAuth 2.0 (Google Авторизация) для привязки аккаунта. PATCH-запросы для сохранения состояния тумблеров (Уведомления, Биометрия). Сессионный logout по кнопке «Выйти из аккаунта» с вызовом окна подтверждения.

## 🗄️ Базовая структура базы данных (SQL для Claude AI)

```sql
-- Таблица пользователей (Экран Профиль)
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) DEFAULT 'Саныч',
    email VARCHAR(150) UNIQUE NOT NULL,
    google_linked BOOLEAN DEFAULT TRUE,
    apple_linked BOOLEAN DEFAULT FALSE,
    notifications_enabled BOOLEAN DEFAULT TRUE,
    autosave_enabled BOOLEAN DEFAULT TRUE,
    biometrics_enabled BOOLEAN DEFAULT FALSE,
    theme_preference VARCHAR(10) DEFAULT 'light'
);

-- Таблица чеков (Экран Камера и История)
CREATE TABLE receipts (
    id SERIAL PRIMARY KEY,
    user_id INT REFERENCES users(id) ON DELETE CASCADE,
    shop_name VARCHAR(150) NOT NULL,
    date_timestamp TIMESTAMP NOT NULL,
    total_amount NUMERIC(10, 2) NOT NULL,
    currency VARCHAR(10) DEFAULT 'Br',
    category_name VARCHAR(100) NOT NULL
);

-- Позиции внутри конкретного чека (Шторка детализации)
CREATE TABLE receipt_items (
    id SERIAL PRIMARY KEY,
    receipt_id INT REFERENCES receipts(id) ON DELETE CASCADE,
    item_name VARCHAR(200) NOT NULL,
    price NUMERIC(10, 2) NOT NULL
);
```
